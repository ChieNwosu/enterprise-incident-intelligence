# Promotion workflow to the knowledge wiki

Notes here are drafts. Promotion into `ChieNwosu/quantpath-llm-wiki` (default branch `master`) is a separate, manual, approved step. This repo does not write to that repository.

Before promoting, read and follow that repository's own conventions:

- `AGENTS.md` and `CLAUDE.md`
- note templates
- folder taxonomy
- maps of content (MOCs)
- the source registry (register each source, including Loghub)
- the system log (record the promotion)

Checklist per note: concept is reusable, provenance cited, evidence links resolve, no third-party dataset content included, license and citation obligations met.
